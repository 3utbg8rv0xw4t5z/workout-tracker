# 🏋️‍♂️ OVERLOAD – Official Landing Page

Willkommen im offiziellen Repository der Webpräsenz für **Overload** (Gym & Progress Tracker). 

Diese Seite dient als interaktiver, mobile-first One-Pager, der die Features der Overload-App vorstellt, Einblicke in smarte Trainings-Tools bietet und direkt zum Download führt.

---

### ✨ Features der Landingpage
* 📱 **Mobile-First Design:** Nahtlose User Experience auf allen Endgeräten
* ⚡ **Leichtgewichtig & Schnell:** Pures HTML5, modernstes CSS & performantes JavaScript
* 🧮 **Interaktive Tools:** Integrierte Rechner & Feature-Previews zur App
* 🚀 **Hosting:** Vollständig automatisiert bereitgestellt über GitHub Pages

---

### 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla ES6+)
* **Hosting:** GitHub Pages
